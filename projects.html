PYTORCH CONTEXT-AWARE NETWORK DJANGO / WAGTAIL OPENCV
Team Project (CrowdVision) · Featured in the UTS AI Showcase 2026

Crowd Counting via Context-Aware Network (CAN)

  • Implemented a Context-Aware Network for crowd density estimation in PyTorch, evaluated on both partitions of the ShanghaiTech benchmark (dense Part A, sparse Part B).
  • Built the full CAN architecture from the 2019 Liu et al. CVPR paper: a VGG16 frontend feeding a multi-scale contextual module (adaptive pooling across four scales with attention-weighted fusion) into a 6-layer dilated convolutional backend producing a density map.
  • Trained with staged fine-tuning — 20 warm-up epochs with a frozen frontend, then differential learning rates — combining MSE density loss with a count regularisation term over 300-epoch runs.
  • Achieved MAE 76.15 / RMSE 110.58 on Part A and MAE 10.58 / RMSE 19.67 on Part B, competitive with the original paper's reported results given single-GPU training.
  • Built a Django/Wagtail web app as the project GUI, supporting drag-and-drop image inference and a live OpenCV webcam feed with real-time inference toggling.

Part B MAE / RMSE 10.58 / 19.67

Australian Trade Visual Analytics

  • Conducted a 35-year visual analysis (1988–2024) of Australia's international trade across 10 categories, engineering raw, statistical, and year-over-year dataset views.
  • Built multi-layered Tableau dashboards (heatmaps, area charts, tree maps) revealing a structural shift in Australia's export economy from agricultural goods to raw commodities, accelerated by the 2008 GFC and 2020 pandemic.
  • Found metalliferous ores accounted for 93.4% of Crude Materials exports in 2021 (peaking at ~$185B); correlated ore exports against steel imports to evidence a structural market decoupling post-2000.
  • Applied Tableau's exponential smoothing forecast model (MAPE 12.8%) to project exports through 2029, cross-validated against AI-generated forecasts.

Smart Car Insurance Cover Recommender

  • Designed a dual-mode recommendation engine behind a swappable interface: a deterministic decision-tree engine as the guaranteed demo fallback, plus a feature-flagged TF-IDF RAG layer over 16 real PDS clauses producing identical outputs on the demo path.
  • Built a gap-surfacing result page showing per-policy excess costs in real dollars (e.g. Rollin' $2,800 vs. NRMA $2,000), with PDS-evidence blockquotes and a confidence meter.
  • Built a responsible-AI trust layer covering AFCA unlisted-driver disclosure, an interactive alternatives explorer, and a "how it works" accordion that echoes the user's own answers back to them.
  • Coordinated a multi-agent parallel build using Git as the sync layer, with a live task board and handoff scripts so any agent could resume cold with zero context loss across 30 sessions.

Facial Expression Recognition

  • Built a multi-model pipeline classifying facial images into 7 emotion categories using the FER2013 dataset (35,887 images).
  • Evaluated three architectures: HOG + SVM baseline, a custom CNN, and MobileNetV2 with two-stage transfer learning.
  • MobileNetV2 performed best (59% test accuracy, macro-F1 0.56); HOG + SVM was competitive at 57.5%, custom CNN reached 52%.
  • Applied CLAHE preprocessing, class-weighted loss, and targeted augmentation to address significant class imbalance.
