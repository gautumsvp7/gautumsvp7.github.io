Projects that have lead me on the jounery of seeking answer in data

Cardiovascular health risk prediction

• Developed a machine learning model to predict cardiovascular disease risk using patient data (blood pressure, cholesterol, glucose, BMI, lifestyle factors).

• Applied preprocessing, feature engineering, and trained multiple classifiers (Random Forest, KNN, Decision Tree, MLP, Stacking).

• Achieved 73% accuracy and 0.79 AUC-ROC with Random Forest.

Technologies: Python, scikit-learn, pandas, matplotlib, Supervised Learning

Asteroid Hazard Prediction

• Built a machine learning pipeline to classify asteroid threats using NASA’s near-Earth object data (diameter, velocity, distance).

• Performed EDA, feature engineering (risk score), and applied MinMaxScaler and SMOTE to address class imbalance.

• Trained a logistic regression model with threshold tuning, achieving 0.94 accuracy and 0.96 ROC AUC

• Evaluated model performance with confusion matrix, classification report, and ROC/PR curves. Exported the model using joblib and integrated it into a web application with the help of AI tools (Gemini, Jules).

Technologies: Python, SMOTE, EDA, Gemini pandas
